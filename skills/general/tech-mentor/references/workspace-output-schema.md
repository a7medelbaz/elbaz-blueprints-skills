# Workspace output schema

Choose the smallest truthful Markdown workspace that supports the goal. For a non-trivial path, the minimum useful map is:

```text
README.md
00-learning-contract.md
01-skills-audit-and-gap-map.md
02-master-roadmap.md
resources.md
```

Add `tracks/<track-name>/`, `projects/`, `progress/`, or `career/` only when each contains substantial independent work. Narrow goals may use fewer files.

`README.md` is the navigation map and must link only to files that exist. Every document labels claims as `verified fact`, `recommendation`, `assumption`, or `learner decision`. Include evidence, checkpoints, review dates, and plan-adjustment rules where relevant. Do not create empty templates or filler sections.
